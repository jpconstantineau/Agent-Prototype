Dashboard components · HTML and CSS

Eight research-backed compositions use supplied page content, the existing palettes and audited CSS. Every value is an illustrative snapshot dated 30 October 2026. These examples do not fetch telemetry, run a clock or use a charting runtime.

Charts.css demonstrates HTML data charts; Carbon, Tremor, Mantine and Adobe Spectrum inform the component choices. These are original limited implementations, with no imported library code. Read the DASHBOARDS.md research and implementation contracts in UI-Spec.

Research and limits

Typed CSS attr() reads validated numeric attributes in current Chrome. Labels, units, periods, trend summaries and exact values remain real HTML. The sparkline assumes evenly spaced, complete samples and a declared common scale. Missing observations need gaps or an explicit unknown state, never a made-up zero. Interactive zoom, sampling, range selection, live refresh and deadlines need application logic. A static duration is not a running countdown.
