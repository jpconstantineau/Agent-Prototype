Reading hierarchy

A 2rem page title, 1.5rem section heading and 1rem body help distinguish a destination from its content.

Help is 0.875rem. Long names and URLs wrap instead of forcing the page wider.

Space means grouping

4, 8, 12, 16, 24, 32 and 48px at the default font size. Small gaps connect related controls; large gaps separate topics.

These panels share a row from 768px and stack below it. The work/support pair uses an 8/4 split from 992px.

Review first. Click to edit.

Open a value’s Edit disclosure with a click, Enter or Space. Change the native field, then Save or Cancel. Leaving a field never saves it. Escape cancels an open editor; Enter in notes inserts a new line.

Why this interaction?

Saved values stay easy to scan. A persistent Edit cue and the browser’s disclosure marker make editing discoverable before hover.

The editor keeps the real label, browser constraints, select arrow and date picker. A draft only replaces the displayed value after successful Save.

Unsaved changes keep an editor open until Save or Cancel. Closing the page clears these demonstration edits.
