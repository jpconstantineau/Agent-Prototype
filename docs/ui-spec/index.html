Reading hierarchy

A 2rem page title, 1.5rem section heading and 1rem body help distinguish a destination from its content.

Help is 0.875rem. Long names and URLs wrap instead of forcing the page wider.

Space means grouping

Normal spacing uses 4, 8, 12, 16, 24, 32 and 48px at the default font size. Compact uses 4, 6, 8, 12, 16, 24 and 32px. Margins separate topics; padding insets content; one gap owns separation inside each group.

Compact reduces the heavier guidance/switch strokes while retaining crisp 1px boundaries and the focus ring. Text size stays the same. These panels share a row from 768px and stack below it.

Why this interaction?

The value is the input. Unfocused fields blend into their panel; focusing reveals the existing control’s border and background without opening a section or swapping elements.

Labels and native select arrows/date pickers stay available. Input padding and border width are reserved in both states so text does not jump on focus.

Draft values remain visible after blur. Save commits this example record; Cancel restores its last saved values. Errors remain marked even after focus leaves.
