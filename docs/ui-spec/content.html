Paragraphs and inline meaning

Body copy uses the system font, a 1rem size and 1.5 line height, capped at 65ch. Important information and stressed wording retain their native meaning. A key term, an alternate voice and a defined concept have separate semantics.

Secondary copy remains readable. A relevant highlighted passage has a neutral frame. The change from automatic approval to explicit review uses line patterns and this written explanation. Outdated information remains available for comparison.

A HMI (human-machine interface) expands on first use. Water is H2O, area is measured in m2, and a revision can use 29 October 2026.

See W3C heading guidance (w3.org). A long identifier wraps: document_revision_identifier_with_a_very_long_unbroken_value_that_must_remain_visible_on_a_narrow_screen.
